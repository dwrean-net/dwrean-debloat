# dwrean.net Debloat

**Ελληνικός, δωρεάν βοηθός για Windows 11**, με επιλογές περιορισμού προτάσεων και περιττών εφαρμογών. Δημιουργήθηκε για το [dwrean.net](https://dwrean.net).

> Έκδοση 1.0.0 — Πρωτότυπη υλοποίηση PowerShell βασισμένη στην ιδέα ενός εργαλείου *debloat*, όχι αντιγραφή του κώδικα τρίτου.

## Τι μπορείς να κάνεις

1. Να μειώσεις διαφημιστικές και εξατομικευμένες προτάσεις των Windows, να κρύψεις Widgets και highlights αναζήτησης.
2. Να ορίσεις την πολιτική διαγνωστικών δεδομένων στο επίπεδο **απαραίτητων δεδομένων**, όπου υποστηρίζεται.
3. Να εμποδίσεις την αποθήκευση νέων στιγμιότυπων από το Windows Recall, όπου ισχύει η σχετική πολιτική.
4. Να προσαρμόσεις ορισμένες ρυθμίσεις Edge (προαιρετικά).
5. Να **επιλέξεις μία προς μία** ορισμένες προαιρετικές εφαρμογές Microsoft, τρίτων ή κατασκευαστή για απεγκατάσταση από **τον τρέχοντα χρήστη**.
6. Να επιστρέψεις στις προηγούμενες **τιμές μητρώου** από αποθηκευμένο αντίγραφο.

## Γρήγορη εκκίνηση με μία εντολή

Μόλις ολοκληρωθεί η δημοσίευση του εργαλείου, άνοιξε **Windows PowerShell**, επικόλλησε αυτή τη μία γραμμή και πάτησε Enter:

```powershell
$u='https://raw.githubusercontent.com/dwrean-net/dwrean-debloat/main/dwrean-debloat.ps1'; $f=Join-Path $env:TEMP 'dwrean-debloat.ps1'; Invoke-WebRequest -UseBasicParsing -Uri $u -OutFile $f -ErrorAction Stop; Start-Process powershell.exe -Verb RunAs -ArgumentList "-NoProfile -ExecutionPolicy Bypass -NoExit -File `"$f`""
```

Η εντολή κατεβάζει το αρχείο από το επίσημο repository στο GitHub, το αποθηκεύει προσωρινά και ξεκινά το Windows PowerShell ζητώντας άδεια διαχειριστή. Το μενού απαιτεί ξεχωριστή επιλογή και επιβεβαίωση για τις αλλαγές.

**Ασφάλεια:** Πρόκειται για απομακρυσμένο script με δικαιώματα διαχειριστή. Έλεγξε τον πηγαίο κώδικα πριν το εκτελέσεις. Η επιλογή `-ExecutionPolicy Bypass` αφορά μόνο αυτή τη νέα διεργασία PowerShell, δεν αλλάζει μόνιμα την πολιτική του συστήματος και δεν εγγυάται ότι το script είναι ασφαλές. Συνιστάται προεπισκόπηση και δοκιμή σε μη κρίσιμο υπολογιστή πριν από την κανονική χρήση.

## Εγκατάσταση και χρήση

Δεν απαιτείται εγκατάσταση. Πάτησε **Code → Download ZIP** στο GitHub και αποσυμπίεσε τα αρχεία. Κάνε διπλό κλικ στο `START-ΕΔΩ.cmd`, αποδέξου την ερώτηση των Windows για δικαιώματα διαχειριστή και διάλεξε μία από τις επιλογές του μενού.

Εναλλακτικά, μέσα από τον φάκελο των αρχείων μπορείς να εκτελέσεις από PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\dwrean-debloat.ps1
```

Για **προεπισκόπηση χωρίς δυνατότητα αλλαγών**:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\dwrean-debloat.ps1 -PreviewOnly
```

Το `-ExecutionPolicy Bypass` αφορά **μόνο τη συγκεκριμένη διεργασία** και δεν αλλάζει μόνιμα τις ρυθμίσεις πολιτικής εκτέλεσης του υπολογιστή. Κατέβαζε scripts μόνο από πηγή που εμπιστεύεσαι και έλεγχε τον κώδικα πριν τα εκτελέσεις ως διαχειριστής.

## Σημαντικές προφυλάξεις

- **Καμία αλλαγή χωρίς προεπισκόπηση και ρητή επιβεβαίωση.** Το πρόγραμμα ζητά να πληκτρολογήσεις `ΕΦΑΡΜΟΓΗ` ή `ΔΙΑΓΡΑΦΗ`.
- Πριν από αλλαγές μητρώου αποθηκεύεται αντίγραφο των προηγούμενων τιμών, μαζί με αναφορά συνεδρίας στο `%LOCALAPPDATA%\dwrean-debloat`. Επιχειρείται και δημιουργία σημείου επαναφοράς όταν υποστηρίζεται από το σύστημα.
- **Η επαναφορά μητρώου δεν εγκαθιστά ξανά εφαρμογές.** Για εφαρμογές που αφαιρέθηκαν, χρησιμοποίησε το Microsoft Store ή τον κατασκευαστή.
- Η επιλογή Recall μπορεί να οδηγήσει σε **οριστική διαγραφή ήδη αποθηκευμένων στιγμιότυπων** από τα Windows. Διάβασε την προειδοποίηση πριν την επιβεβαιώσεις.
- Οι ρυθμίσεις πολιτικών `HKLM` ίσως δεν έχουν αποτέλεσμα σε Windows Home ή σε ορισμένες εκδόσεις Windows 11. Η πολιτική διαγνωστικών δεν σημαίνει μηδενική συλλογή δεδομένων.
- Οι πολιτικές Edge μπορεί να προκαλέσουν εμφάνιση της φράσης «Διαχειρίζεται από τον οργανισμό σας» στον Edge.
- **Δεν** διαγράφει προσωπικά αρχεία, σελιδοδείκτες, γλώσσες Office, drivers, Windows Update, προστασία antivirus ή υπηρεσίες συστήματος. Δεν απεγκαθιστά σιωπηρά εφαρμογές τρίτων· ακόμη και Spotify, Netflix ή Roblox αφαιρούνται μόνο αν τα επιλέξεις ρητά.
- Η λίστα κατασκευαστών αφορά μόνο συγκεκριμένα **Appx/MSIX**, όχι κλασικές εφαρμογές Win32 και όχι κάθε OEM υπολογιστή. Δεν είναι πλήρης αντικατάσταση του αρχικού εργαλείου.
- Χρησιμοποίησέ το σε προσωπικό PC, όχι σε υπολογιστή εταιρείας/σχολείου με κεντρική διαχείριση. Ακόμη και επιλεγμένες εφαρμογές μπορεί να σου χρειάζονται.
