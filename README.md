## Τι είναι το dwrean.net Debloat;

Τα Windows 11 περιλαμβάνουν προτάσεις, πρόσθετες εφαρμογές και διάφορες προαιρετικές λειτουργίες που μπορεί να μη χρειάζεσαι. Το **dwrean.net Debloat** σε βοηθά να τις διαχειριστείς από **ένα απλό, ελληνικό μενού**, χωρίς να χρειάζεται να αναζητάς μία προς μία τις αντίστοιχες ρυθμίσεις.

Δεν είναι «μαγικός επιταχυντής» των Windows ούτε εκτελεί μαζικές διαγραφές. **Εσύ επιλέγεις** ποιες αλλαγές θα γίνουν. Το εργαλείο δείχνει τις ενέργειες πριν από την εφαρμογή τους και ζητά ρητή επιβεβαίωση.

> [!IMPORTANT]
> Το πρόγραμμα μεταβάλλει ρυθμίσεις Windows και μπορεί, κατόπιν επιλογής σου, να απεγκαταστήσει εφαρμογές. Διάβασε τις προειδοποιήσεις και προτίμησε πρώτα τη λειτουργία προεπισκόπησης. Χρησιμοποίησέ το σε προσωπικό υπολογιστή, όχι σε συσκευή εταιρείας ή σχολείου με κεντρική διαχείριση.

## 🚀 Γρήγορη εκκίνηση

Άνοιξε το **Windows PowerShell** στα Windows 11, κάνε αντιγραφή **ολόκληρης** της παρακάτω εντολής και πάτησε **Enter**:

~~~powershell
$u='https://raw.githubusercontent.com/dwrean-net/dwrean-debloat/main/dwrean-debloat.ps1'; $f=Join-Path $env:TEMP 'dwrean-debloat.ps1'; Invoke-WebRequest -UseBasicParsing -Uri $u -OutFile $f -ErrorAction Stop; Start-Process powershell.exe -Verb RunAs -ArgumentList "-NoProfile -ExecutionPolicy Bypass -NoExit -File `"$f`""
~~~

Η εντολή **κατεβάζει πρώτα το script από αυτό το repository** στον προσωρινό φάκελο και στη συνέχεια το ανοίγει σε νέο παράθυρο PowerShell με αίτημα δικαιωμάτων διαχειριστή. Δεν χρειάζεται εγκατάσταση.

> [!CAUTION]
> Η εκτέλεση απομακρυσμένου script ως διαχειριστής έχει κινδύνους. [Έλεγξε τον πηγαίο κώδικα](dwrean-debloat.ps1) πριν χρησιμοποιήσεις την εντολή. Το `-ExecutionPolicy Bypass` ισχύει μόνο για τη νέα διεργασία PowerShell, **δεν** είναι πιστοποίηση ασφάλειας και δεν απενεργοποιεί το Microsoft Defender.

### Εναλλακτικά: λήψη ZIP

1. Πάτησε **[Code → Download ZIP](https://github.com/dwrean-net/dwrean-debloat/archive/refs/heads/main.zip)** και αποσυμπίεσε τον φάκελο.
2. Άνοιξε το **[START-ΕΔΩ.cmd](START-%CE%95%CE%94%CE%A9.cmd)** με διπλό κλικ.
3. Αποδέξου το αίτημα των Windows για δικαιώματα διαχειριστή και επίλεξε τι θέλεις από το μενού.

Για εκτέλεση απευθείας από τον φάκελο του script:

~~~powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\dwrean-debloat.ps1
~~~

### Δοκίμασε πρώτα χωρίς αλλαγές

Από τον φάκελο που περιέχει το `dwrean-debloat.ps1`:

~~~powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\dwrean-debloat.ps1 -PreviewOnly
~~~

Η παράμετρος `-PreviewOnly` εμφανίζει τις διαθέσιμες ενέργειες, χωρίς να εφαρμόζει αλλαγές ή να αφαιρεί εφαρμογές. Μπορεί να δημιουργηθεί αρχείο καταγραφής της συνεδρίας.

## 🛡️ Σημαντικές προφυλάξεις

- **Δεν γίνεται αυτόματη μαζική απεγκατάσταση.** Το εργαλείο εμφανίζει μόνο τις εφαρμογές που εντοπίζει και σε αφήνει να επιλέξεις συγκεκριμένους αριθμούς. Η αφαίρεση γίνεται για τον **τρέχοντα λογαριασμό Windows**, όχι για όλους τους χρήστες.
- **Ζητείται επιβεβαίωση** με τις λέξεις `ΕΦΑΡΜΟΓΗ`, `ΔΙΑΓΡΑΦΗ` ή `ΕΠΑΝΑΦΟΡΑ` ανάλογα με την ενέργεια.
- **Πριν από αλλαγές στο μητρώο**, δημιουργείται αντίγραφο των προηγούμενων τιμών. Το πρόγραμμα **επιχειρεί** και δημιουργία σημείου επαναφοράς συστήματος· αυτό δεν είναι εγγυημένο.
- **Η επιλογή Recall χρειάζεται ιδιαίτερη προσοχή:** η εφαρμογή της πολιτικής μπορεί να προκαλέσει **οριστική διαγραφή ήδη αποθηκευμένων στιγμιότυπων** από τα Windows.
- **Οι αλλαγές δεν ισχύουν παντού:** κάποιες πολιτικές διαφέρουν ανά έκδοση/έκδοση Home ή Pro των Windows 11. Ο Edge ενδέχεται να εμφανίσει το μήνυμα «Διαχειρίζεται από τον οργανισμό σας».
- **Η επαναφορά αφορά μόνο τιμές μητρώου. Δεν επανεγκαθιστά εφαρμογές.** Ό,τι αφαιρεθεί μπορεί να χρειάζεται νέα εγκατάσταση από το Microsoft Store ή τον κατασκευαστή.
- Το script **δεν** διαγράφει προσωπικά αρχεία, σελιδοδείκτες, γλώσσες Office, drivers, προστασία antivirus ή υπηρεσίες συστήματος.
- Δεν υπόσχεται συγκεκριμένη αύξηση ταχύτητας, μνήμης RAM ή FPS.
